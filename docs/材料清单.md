## 6. 选型说明

| 部件 | 为什么选它 | 替代方案 |
|---|---|---|
| 犀牛派 X1 | 自带 NPU 跑本地 VLM，AidLux 预装 ROS 2 | 其他 ARM64 + NPU 平台需自行适配 |
| RPLidar A1 | 便宜、驱动成熟、7.7Hz 够用 | A2/A3（10~15Hz，更贵） |
| MPU6050 | 便宜、I²C、100Hz | ICM20602（更稳，需改驱动） |
| L298N | 便宜、逻辑简单 | TB6612（效率高、体积小） |
| 阿克曼底盘 | 转向平滑、接近真实车辆 | 差速底盘（可原地转，窄处更灵活） |

## 7. 采购注意

1. **MPU6050 模块质量参差**：本项目实测多块模块存在零偏过大/陀螺无输出，建议买带"正品芯片"标注的，
   或直接选 ICM20602（需改驱动，`slam/mpu6050_node.py`）。
2. **云台协议**：不同厂家协议不同，本项目的 6 字节帧协议见 `gimbal/gimbal_wiring.md`；买前确认。
3. **L298N 压降约 1.5~2V**：12V 电池实际到电机约 10V，注意速度匹配。
4. **舵机供电**：不要与板卡共用排针 5V，建议独立 BEC 并共地。
