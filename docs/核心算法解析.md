# 核心算法解析

本文说明各关键算法的**输入、输出、约束与失效处理**，对应代码位置在每节末尾标注。

---

## 1. 激光 + 陀螺里程计

### 1.1 为什么不用轮式编码器做主里程计

阿克曼底盘在低速转向时，前轮转角与后轮差速关系不固定，轮式里程计在转向时误差大；
且编码器只有 4 路 GPIO 采样，抖动明显。因此本项目采用**激光匹配为主、陀螺仪约束航向**的方案。

### 1.2 数据流

```
/scan (7.7Hz) ──┐
                ├──> laser_imu_odom ──> /odom + TF(odom→base_link)
/imu/data_raw ──┘        (100Hz)
```

### 1.3 平移：ICP 点对面匹配

对相邻两帧扫描做 ICP（迭代最近点）：

$$
\min_{R,t}\sum_i \|R\,p_i + t - q_i\|^2
$$

- 初值来自上一帧位姿 + 陀螺积分航向；
- 迭代上限与收敛阈值在 `laser_odom_core.py`；
- 匹配残差 `residual` 超阈值 → **拒绝该帧**，不发布假位姿；
- 连续拒绝 → 进入 `laser-only` 降级，并记录 `rejected` 计数。

### 1.4 航向：陀螺积分 + 关键帧约束

陀螺角速度按时间戳梯形积分：

$$
\Delta\theta = \tfrac{1}{2}(\omega_k + \omega_{k+1})\,\Delta t
$$

约束点：

1. **时间对齐**：用扫描时间戳区间内的陀螺样本积分，缺失覆盖则返回 `None`（退回纯激光）。
2. **安装方向**：标定时用重力向量求 `up` 轴，角速度投影到 `up` 得到偏航角速度：

$$
\omega_{yaw} = \vec{\omega}\cdot \hat{u}
$$

3. **关键帧**：位姿变化超过阈值才建关键帧，减少累计误差。
4. **跳变保护**：单帧位移/角度超限 → 重新锚定，不输出跳变位姿。

### 1.5 输出

- `/odom`：`nav_msgs/Odometry`，含 `twist`（线速度由位移差分，角速度由陀螺）；
- TF：`odom → base_link`（唯一发布者）；
- 诊断：`good/rejected/gyro_frames/residual` 计数，供网页与日志观测。

> 代码：`slam/laser_imu_odom.py`、`slam/gyro_core.py`、`slam/laser_odom_core.py`

## 2. 建图（slam_toolbox）

- 模式：**异步**（`async_slam_toolbox_node`），允许建图时继续接收扫描。
- 输入：`/scan` + `/odom` + TF。
- 关键参数：

| 参数 | 值 | 说明 |
|---|---|---|
| `resolution` | 0.05 | 5cm/像素 |
| `max_laser_range` | 8.0 | 与雷达一致 |
| `minimum_time_interval` | 0.5 | 建图节流 |
| `transform_timeout` | 0.5 | TF 容忍 |
| `base_frame` | `base_link` | **必须与静态 TF 一致**，否则地图全空 |

- 保存：`map_saver.py` 直接订阅 `/map` 写 PGM+YAML，不依赖 `nav2_map_server`。

> 代码：`slam/mapping_ctl.sh`、`slam/map_saver.py`、`slam/mapping_no_odom.yaml`

## 3. 定位（AMCL）

- 粒子滤波，激光模型为 likelihood_field。
- 关键参数：

| 参数 | 值 |
|---|---|
| `max_beams` | 35 |
| `laser_max_range` | 8.0 |
| `update_min_d` | 0.02 m |
| `update_min_a` | 0.03 rad |
| `transform_tolerance` | 0.5 s |

- **收敛判据**：位姿协方差 < 0.25，且连续若干帧稳定。
- 未收敛时：导航/巡检拒绝运动（`localization_settle.py`）。
- 纯旋转期间协方差会短时升高，巡检在 `rotating/direct` 阶段对定位做**宽限**（1.5s），
  但仍要求位姿可用。

> 代码：`navigation/navigation_launch.py`、`navigation/localization_settle.py`

## 4. 路径规划（Smac Hybrid-A\*）

- 运动模型：DUBIN（允许倒车），最小转弯半径 `R=0.65m`。
- 代价地图：`inflation_radius=0.30`，`cost_scaling_factor=5.0`，`allow_unknown=true`。
- 规划时间上限 5.0s，迭代上限 200000。

**为什么用 Hybrid-A\***：阿克曼底盘不能原地转向，普通 A\* 的折线路径不可执行；
Hybrid-A\* 在 (x, y, θ) 状态空间搜索，输出满足转弯半径的平滑路径。

**已知现象**：目标距离小于约 1.2m 时，DUBIN 在狭窄空间可能规划出"绕一圈"的路径。
因此巡检对 ≤2m 的短段改用**直行段**（`direct`），不走 Nav2。

> 代码：`navigation/build_nav_params.py`、`navigation/navigation_launch.py`

## 5. 轨迹跟踪（Regulated Pure Pursuit）

- 前视距离随速度自适应；
- 曲率：

$$
\kappa = \frac{2\sin\alpha}{L_d}
$$

- 输出 `cmd_vel`（线速度 + 角速度），经 `velocity_smoother` 限加速度后下发。

### 5.1 舵角换算（阿克曼）

$$
\delta = \arctan\!\left(\frac{L\,\omega}{v}\right)
$$

`L` 为轴距（实测 0.20m）。接近终点时 `v→0`，该式发散，因此对 `δ` 做钳位并有最小速度保护。

## 6. 监督试航包络

Nav2 的速度**不直接**给电机，而是经过 `navigation_drive.py`：

```
cmd_vel → TrialDrive.step() → (l, a, rot) → PWM
```

### 6.1 限幅

| 量 | 上限 |
|---|---|
| 线速度 | 0.28 m/s |
| PWM | 0.45 |
| 舵角 | 25° |
| 前方净空 | 0.20 m |
| 单段距离/时长 | 10 m / 300 s |

### 6.2 速度反馈

用 `stage1/core.py` 的 `Feedback`（带死区的比例控制）：

$$
duty = k_p\,(v_{ref} - v_{meas}) + duty_{ff}
$$

`duty_cap` 限制输出；`dt` 超过 0.5s 视为进程停顿，重置控制器并输出 0。

### 6.3 实测速度异常

连续 3 帧 `v_meas ∉ [-0.03, 0.60]` → 判定"实测速度异常"并停止。
该判据用于捕捉**里程计跳变或轮子打滑**，但需注意：启动瞬间的里程计尖峰也会触发。

## 7. 巡检状态机

```
        ┌──────────────────────────────────────────┐
        ▼                                          │
   idle ──start──> navigating ──Nav2成功──> dwell ──┤
                     │  (≤2m)                    │
                     └──> direct ──到点──────────┘
                                        │
                                   dwell(停稳5s)
                                        │
                                    detecting
                                        │
                               记录 + 报告 → 下一点
```

### 7.1 到点判定

$$
d = \sqrt{(x-x_g)^2 + (y-y_g)^2} < 0.20
$$

或"冲过头"：最近距离 < 0.6m 且当前距离 > 最近距离 + 0.30m。

### 7.2 停稳判定

| 条件 | 阈值 |
|---|---|
| 里程计新鲜度 | ≤ 2.0 s |
| 线速度安静 | ≤ 0.04 m/s |
| 角速度安静 | ≤ 0.10 rad/s |
| 漂移 | ≤ 5 cm / 0.08 rad |

连续满足才进入 `detecting`；超时 25s 判失败。

### 7.3 卡住检测

直行段：12s 内距离没有减少 5cm → "直行卡住"。
导航段：单段 60s 未到 → "直行段超时"。

### 7.4 守护（_guard）

每个 tick 检查：心跳、armed、驾驶权、定位可用。巡检自己负责的部分（停稳/检测阶段）
豁免"指令超时"，但**不豁免**传感器/定位/使能。

> 代码：`navigation/patrol_runner.py`

## 8. 火情判定

1. 相机帧（JPEG）→ 本地 VLM（Qwen2.5-VL 3B QNN）。
2. 提示词要求模型输出结构化结论：`{"verdict": "clear|fire|smoke", "reason": "..."}`。
3. 解析失败/超时 → `unknown`，不作为异常，但记录待复核。
4. 证据：保存原始帧 + 缩略图 + 时间戳，写入 `data/inspections/<id>/`。
5. 报告：按点位与区域汇总，输出 Markdown/HTML。

> 代码：`inspection/inspection_service.py`、`inspection/local_model.py`、`camera/fire_detect.py`

## 9. 网页实时链路

| 环节 | 设计 |
|---|---|
| 遥测下发 | SocketIO 广播，节流到 10Hz（地图/扫描按帧） |
| 摇杆上行 | 60Hz，UDP 直发 `pwm_proc`（不经 ROS） |
| 驾驶权 | 稳定 CLIENT_ID + 6s 断线宽限 |
| 页面不可见 | 前端停发（浏览器会把后台定时器钳到 1Hz，触发 deadman 抖动） |
| 心跳 | 200ms/次，1.2s 无心跳取消导航 |

> 代码：`web/slam_viz.py`、`web/web_drive_test.js`

## 10. 算法层面的已知问题

| 问题 | 现象 | 处理 |
|---|---|---|
| ICP 在长走廊退化 | 位移估计漂移 | 拒绝低置信匹配，提示重新定位 |
| 陀螺零偏温漂 | 长时旋转航向偏 | 每次启动静止标定；关键帧重锚 |
| DUBIN 短距绕圈 | 1.2m 内目标规划异常 | ≤2m 用直行段 |
| AMCL 纯旋转协方差高 | 旋转时定位暂停 | 旋转段宽限 1.5s |
| VLM 偶发返回无关文本 | 结论不可靠 | 置信度 + 人工复核标记 |
