# 代码结构说明

## 1. 分层与依赖

```
web/            ← 表现层：页面 + SocketIO + 驾驶权
  │  调用
  ▼
navigation/     ← 业务层：地图、Nav2 生命周期、试航包络、巡检验证
inspection/     ← 业务层：记录与报告、VLM 调用
  │  调用
  ▼
slam/  motor/  gimbal/  camera/   ← 驱动层：传感器、执行器、ROS 桥接
  ▲
tools/  stage1/  stage2/          ← 工具与验收（不参与运行）
```

依赖方向**单向向下**：驱动层不 import 业务层；`web/` 只通过 `navigation/` 暴露的接口驱动硬件。

## 3. 关键类与函数

### 3.1 `NavigationRuntime`（navigation_runtime.py）

| 成员 | 说明 |
|---|---|
| `tick()` | 主循环：读位姿 → 检查门控 → 计算速度 → 下发 |
| `start()` / `cancel()` | 启动/取消导航（取消会 disarm） |
| `send_drive(l, a, armed, rot)` | 输出到 pwm_proc 的唯一出口 |
| `_guard` 相关 | 心跳、传感器、定位、使能、指令超时 |
| `patrol_runner` | 巡检执行器（组合） |

### 3.2 `TrialDrive`（navigation_drive.py）

```python
step(v, w, measured_v, dt) -> (l, a, rot)
```

- 入口做有限值与 `dt` 检查；
- `v<0` 或超限 → 抛错；
- 连续 3 帧实测速度越界 → 抛 `实测速度异常`；
- `v≈0` 且 `|w|>0.25` → 原地旋转（巡检已禁用）；
- 否则按 `δ=atan(Lω/v)` 算舵角并钳位。

### 3.3 `PatrolRunner`（patrol_runner.py）

| 状态 | 行为 |
|---|---|
| `navigating` | 下发 Nav2 目标，等待结果 |
| `direct` | ≤2m 直行，带进度/净空/传感器检查 |
| `dwell` | 停稳确认 |
| `detecting` | 取图 + VLM |
| `reporting` | 汇总报告 |

### 3.4 `InspectionService`（inspection_service.py）

- `record(id, automatic=True)`：新建记录，启动采样线程；
- `finish(id)`：收尾并生成报告；
- `statistics()`：按区域/点位汇总。

### 3.5 `map_store.MapStore`

- `path(name)` / `list()` / `save()` / `delete()`（移入 `.trash/`）；
- `regions(name)` / `save_regions(name)`：语义区域（世界坐标多边形）；
- `info()` / `inventory()`：缩略图、正式图标记。

## 4. 数据格式

### 4.1 地图目录

```
data/maps/<名称>/
├── map.pgm           # 占据栅格
├── map.yaml          # 分辨率、原点
├── thumbnail.png     # 缩略图
├── meta.json         # 名称、时间、尺寸、来源
├── regions.json      # 语义区域 [{name, polygon:[{x,y}...]}]
└── .official         # 正式图标记（存在即正式）
```

### 4.2 巡检记录

```
data/inspections/<id>/
├── session.json      # 任务、状态、记录列表、结论
├── report.md         # 生成的报告
├── <point>-<ts>.jpg  # 证据原图
└── thumb-*.jpg       # 缩略图
```

### 4.3 路线

```json
{
  "name": "zhou_lang",
  "map": "zou_lang",
  "cycles": 1,
  "revision": 3,
  "waypoints": [{"x": 4.78, "y": -0.99, "yaw": -3.11, "dwell_s": 5}]
}
```

## 5. 测试组织

| 层级 | 方式 | 例子 |
|---|---|---|
| 纯函数 | Python `unittest`，无 ROS/GPIO | `gyro_core.py`、`motor_control.py`、`gimbal_proto.py` |
| 集成 | 假 ROS/假硬件 | `patrol_runtime_test.py`、`web_navigation_test.py` |
| 前端 | Node + 假 DOM | `web/web_drive_test.js` |
| 板端 | 只订阅不驱动 | `navigation_smoke.py`、`autonomy_smoke.py` |

运行：

```bash
python3 -m pytest navigation/ motor/ gimbal/ inspection/ -q
node web/web_drive_test.js
```
