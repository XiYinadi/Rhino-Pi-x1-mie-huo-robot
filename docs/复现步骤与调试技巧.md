# 复现步骤与调试技巧

> 目标：从零把一台同配置的车带到"能自动巡检"。每一步都有**可观测的验证点**，不通过不要往下走。

## 1. 硬件装配（顺序不要乱）

### 1.1 供电与共地

1. 电池 → 稳压模块 → 板卡 5V（**先不接电机**）。
2. 所有模块 **GND 共地**（板卡、L298N、舵机、云台、相机）。
3. 上电量板卡 5V：应为 4.9~5.1V；3.3V 排针应为 3.2~3.4V。

> ⚠️ 排针 5V 同时供 L298N 逻辑、相机、舵机，**没有电流预算文档**。云台请单独 5V 供电并共地。

### 1.2 电机与舵机

按 `motor/motor_wiring.md` 接线：

| 通道 | 排针 | GPIO | 驱动 |
|---|---|---|---|
| 通道 L（PWM/IN1/IN2） | 32/18/31 | 91/61/62 | **右轮** |
| 通道 R（PWM/IN3/IN4） | 36/37/33 | 63/60/124 | **左轮** |
| 舵机信号 | 28 | 33 | 转向舵机 |

接完先架空，用 `tools/wheel_dir_probe.py` 逐通道验证方向：

```bash
pkill -f 'python3 .*pwm_proc.py'
python3 ~/robot/tools/wheel_dir_probe.py
```

观察哪一段是"车轮向前"，据此设置 `flip_left/flip_right`（见 `motor_wiring.md` 的方向表）。

### 1.3 雷达

```bash
ls -l /dev/ttyUSB0        # 应为 ttyUSB0
python3 ~/robot/tools/topic_probe.py /scan
```

### 1.4 姿态传感器（GY-521）

| GY-521 | 排针 |
|---|---|
| VCC | pin 1（3.3V） |
| GND | pin 6 |
| SDA | pin 3（I2C1_SDA） |
| SCL | pin 5（I2C1_SCL） |
| AD0 | GND（地址 0x68） |

验证：

```bash
python3 ~/robot/tools/enc_dir_test.py   # 编码器/方向
# 读芯片
python3 - <<'PY'
import fcntl
fd=open('/dev/i2c-1','r+b',buffering=0); fcntl.ioctl(fd,0x0703,0x68)
fd.write(bytes([0x75])); print('WHO_AM_I', hex(fd.read(1)[0]))
PY
```

期望 `0x68`。

### 1.5 相机

```bash
v4l2-ctl --list-devices      # 找 "USB 2.0 Camera"
```

⚠️ 认设备名，不要认 `/dev/videoN` 编号（会变）。相机**单读**，只能一个进程持有。

### 1.6 云台

只接 **TX（pin29）+ GND（pin30）**，不接 RX。详见 `gimbal/gimbal_wiring.md`。

## 3. 分步启动与验证

### 3.1 电机

```bash
bash ~/robot/motor/start_pwm.sh
tail -f /tmp/pwm_proc.log
```

期望每 5 秒一行：

```
[pwm_proc] 摇杆 60包/s 轮询 200Hz 龄期 10ms armed=N steer=servo l=+0.00 duty L=0.00 R=0.00 dir L=1 R=1
```

网页 `http://<IP>:5800/control` → 点"启用电机" → 轻推摇杆。

### 3.2 姿态与里程计

```bash
ros2 topic hz /imu/data_raw     # ~100Hz
ros2 topic hz /odom             # ~7.7Hz
ros2 run tf2_ros tf2_echo odom base_link
```

IMU 启动时会静止标定 3 秒，日志应出现 `Calibration ready bias_rad_s=[...]`。
如果反复出现 `Sensor moving during calibration`，见 FAQ。

### 3.3 建图

```bash
bash ~/robot/slam/mapping_ctl.sh start
bash ~/robot/slam/mapping_ctl.sh status
```

网页建图页应看到扫描与地图逐步成型。走完一圈后保存地图。

### 3.4 定位

网页地图管理选地图 → 加载定位 → 拖拽初始位姿 → 等待协方差 < 0.25。

验证：

```bash
ros2 topic echo /amcl_pose --once
```

### 3.5 导航与巡检

1. 导航页选点 → 预览路线（确认不绕圈）。
2. 启动导航，观察 `/cmd_vel` 与轮子。
3. 巡检页画 3~4 个点 → 预览 → 启动。

## 4. 标定

| 项 | 方法 | 目标值 |
|---|---|---|
| 转弯半径 | 满舵画圆，量半径 | 约 0.65m |
| 舵角映射 | 打满舵量前轮角度 | 25° |
| 速度 | 直行 3m 计时 | 与实际一致 |
| 陀螺零偏 | 静止启动自动标定 | 记录在日志 |
| 相机内参（可选） | 棋盘格 | 用于测距时 |

标定后写入 `navigation/navigation_calibration.yaml` 与 `motor/motor_params.yaml`。

## 5. 调试技巧

### 5.1 分层定位问题

| 现象 | 先查 | 命令 |
|---|---|---|
| 车不动 | 是否 armed / deadman | `tail /tmp/pwm_proc.log` |
| 车跑偏 | 左右轮方向/极性 | `tools/wheel_dir_probe.py` |
| 地图不更新 | 里程计/TF | `ros2 topic hz /odom`、`tf2_echo` |
| 定位飘 | AMCL 协方差 | `ros2 topic echo /amcl_pose` |
| 规划失败 | 起点是否在障碍里 | 换起点，看 `navigation.log` |
| 巡检到点不停 | 到点半径/冲过头 | 看报告里的 `arrival_basis` |
| 网页控制延迟 | 网络/包率 | `tools/diag_client.py` |

### 5.2 不用浏览器的注入测试

```bash
python3 ~/robot/motor/joy_inject.py --arm --wheel L     # 单轮
python3 ~/robot/motor/joy_inject.py --sweep             # 扫启动阈值
python3 ~/robot/gimbal/gimbal_inject.py --axis-sweep    # 云台方向
```

### 5.3 日志位置

| 日志 | 内容 |
|---|---|
| `/tmp/pwm_proc.log` | 电机状态（5 秒一行） |
| `/tmp/navigation.log` | Nav2 / 里程计 / AMCL |
| `/tmp/servo_proc.log` | 舵机 |
| `/tmp/gimbal_proc.log` | 云台 |
| `journalctl -u rhino-web` | 网页服务 |

### 5.4 常见坑（都真实踩过）

1. **参数软链接被替换**：`~/motor_params.yaml` 变成普通文件后，改 `flip_*` 怎么重启都不生效。
   `start_pwm.sh` 已加自动修复，也可手动 `ls -l ~/motor_params.yaml` 确认。
2. **pwm_proc 与 motor_driver 互斥**：两者抢同一批 GPIO，后启动的报 line busy。
3. **地图起点离墙太近**：规划 ABORTED（status=6），把车挪开 0.5m 再试。
4. **短距离目标绕圈**：DUBIN 在 1.2m 内可能画圈，≤2m 用直行段。
5. **IMU 标定失败**：噪声门限 0.05 rad/s，若模块噪声大，先固定安装再试。
6. **网页控制延迟**：确认页面可见（后台标签页会被浏览器节流到 1Hz）。
7. **VLM 报告拖垮板卡**：长提示词/连续调用会让 SSH 掉线，测试时短时单发。
