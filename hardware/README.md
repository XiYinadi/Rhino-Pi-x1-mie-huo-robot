## 一、扩展板（犀牛派 40-Pin 引出板）

把犀牛派 X1 的 40-Pin 排针引出为**螺钉端子**，避免杜邦线在振动下松脱。

| 位号 | 名称 | 类型 / 规格 | 说明 |
|---|---|---|---|
| `CN1` | 犀牛派 40-Pin 主排针（上） | 2×20, 2.54mm, `LAL-SIL-2.54-2x20P-ZC` | 与 `CN2` 配对，插犀牛派 X1 |
| `CN2` | 犀牛派 40-Pin 主排针（下） | 2×20, 2.54mm, 同上 | 与 `CN1` 配对 |
| `DC1` | 12V 电源输入 | DC 电源座 | 整机主电源 |
| `H1` | 电机驱动 | 2×5 螺钉端子 | L298N 方向/PWM 信号引出 |
| `H2` | 舵机 | 1×3 螺钉端子 | 转向舵机（信号 / 5V / GND） |
| `H3` | 3.3V 电源 | 2×5 螺钉端子 | 传感器供电（GY-521 等） |
| `H4` | 5V 电源 | 2×5 螺钉端子 | 相机 / 逻辑供电 |
| `H5` | 串口 L | 1×4 螺钉端子 | UART 外设（VCC/GND/TX/RX） |
| `H6` | 串口 R | 1×4 螺钉端子 | UART 外设（VCC/GND/TX/RX） |
| `H7` | 串口扩展 | 2×5 螺钉端子 | 备用 UART / 调试 |

**设计规则**：2 层板；端子间距 2.54mm；电源与信号分层走线，地平面完整；
图幅 A4 单页；版本 V1.0，创建 2026-09-27，更新 2026-10-14；设计工具 嘉立创 EDA 专业版 V3.2。

## 二、云台控制板（STM32F103C8T6）

- 主控：STM32F103C8T6 最小系统板
- 串口：USART2（PA2=TX / PA3=RX），115200 8-N-1
- 输出：两轴 STEP/DIR/EN（X：PA4/PA5/PA6；Y：PB0/PB1/PB10）
- 电源：3.3V / 5V 端子，4 个安装孔
- 原理图见 `接线图-云台控制板.pdf`，固件见 `firmware/`

协议（与 [`gimbal/gimbal_proto.py`](../gimbal/gimbal_proto.py) 完全一致）：

```
速度帧：0xAA | dxH dxL | dyH dyL | SUM      (int16 大端，速度锁存)
动作帧：0xBB | cmd 0 0 0 | SUM             (1=角度清零，2=开环回零)
```

## 四、图纸重新导出方法

1. 用**嘉立创 EDA 专业版**打开 `犀牛派引出板.epro2`
2. 原理图页 → **文件 → 导出 → PDF**（A4、100%）
3. PCB 页 → **文件 → 导出 → PDF**（选择需要的层）、**文件 → 导出 → STEP**
4. 覆盖本目录同名文件即可
